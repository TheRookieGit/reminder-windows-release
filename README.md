# Mac Reminders & Notes 安装包

这里只存放 Mac Reminders & Notes（在 Windows 上查看和修改 Mac 的提醒事项和备忘录）的安装包，供下载安装和应用内自动更新使用。安装包里没有任何提醒事项或备忘录：数据只能通过 Tailscale 从配对过的 Mac 读取和修改。

到 [Releases](https://github.com/TheRookieGit/reminder-windows-release/releases/latest) 下载最新的 `Mac-Reminders-Notes-Setup-x.y.z.exe`。装好后应用会自动检查并安装更新。

> 安装包没有代码签名，第一次运行 Windows 可能提示「已保护你的电脑」，点「更多信息 → 仍要运行」即可。
